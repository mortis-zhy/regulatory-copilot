## 两个踩过的坑（改脚本前先看）

1. **别内嵌中文字体**。四套字体 base64 后是 **97 MB 的 HTML**，
   Chromium 会在 `setContent` 阶段直接撑爆浏览器进程
   （`Target page, context or browser has been closed`）。
   宣讲稿只在本机生成，用系统字体（`Microsoft YaHei` / `SimSun`）即可。

2. **图表必须按实际显示宽度渲染**。页面可用宽度 1188 CSS px，
   图表就按 1188 渲染 —— 1:1 不缩放，字才看得清。
   早先按 1400 渲染再缩到 1188，表格里的字缩到 13px 以下，投屏根本看不清。
