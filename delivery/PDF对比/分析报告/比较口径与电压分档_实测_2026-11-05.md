## 一、两条缺陷，都是「维度缺失」

### DR-001：一行装了三档电压，行名却写着其中一档

矩阵里那一行的名字是「终端稳态电压上限（**12V 系统**）」，而它的三格是：

| 版 | 取值 | 实际含义 |
|---|---|---|
| A | 13.5 / 28 | 12V 档 13.5 V **+ 24V 档 28 V** |
| B | 6.75 / 13.5 / 28 | **三档都在** |
| C | 6.75 / 13.5 / 28 | **三档都在** |

读者看到 A 那一格「13.5/28」，**看不出哪个数属于哪一档**；
而结论是「**A 删除 6V 档，12V/24V 未变**」——
这正是客户 DR-001 写的「拆成 6V、12V、24V 三行」。

### DR-002：只比较数字，**丢了比较符号**

矩阵的判定只比 `nums`（数字列表）。而
「离地高度**小于** 750 ㎜」与「离地高度**不大于** 750mm」的 `nums` **都是 ["750"]** ——
于是它们被判成「A/B 一致」。

**恰好 750 mm 时适用性不同**：B 允许把可见度角减到 5°，A 不允许。

## 三、修法：口径是**数据**，不是措辞

### ① 口径从**原文**里取（`server/reports/parameterMatrix.ts`）

新增 `Cell.comparator`（`<` / `≤` / `≥` / `>` / `=`），
由 `comparatorBefore()` 取**紧贴取值前面**的比较词：

- 比较词与取值之间只允许隔**空白与单位**（否则抓到的是别的数的口径）；
- 到最近的句读为止（比较词必须属于**这一句**）；
- 认不出就是认不出 —— **留空，不猜**。

### ② 否定词把方向**翻过来**（最容易把结论说反的一处）

| 原文 | 限值关系 | 口径 |
|---|---|---|
| 小于 750 | 值 < 750 | `<` |
| **不大于** 750 | 值 ≤ 750 | `≤` |
| **不小于** 600 | 值 ≥ 600 | `≥` |
| **不应小于** 600 | 值 ≥ 600 | `≥` |

「距离**不应小于** 600mm」是**下限** 600 ——
判成「小于」就把下限说成了上限。

### ③ 英文的等价式与陷阱（R48 那一版）

| 原文 | 口径 |
|---|---|
| shall not exceed X | `≤` |
| no more than X / nor more than X | `≤` |
| less than **or equal to** X | `≤` |
| equal **or less than** X | `≤` |
| **not less than** X | `≥` |
| at least X | `≥` |
| below X | `<` |
| the deviation … **differs by more than** 0.15 | **留空** |

最后一条为什么留空：它说的其实是「偏差**不得大于** 0.15」（限值关系 `≤`），
但裸的「more than」判成「>」就是**反的** ——
**宁可留空（少一个维度），不可猜错（把法规结论说反）**。

### ④ 判定多一种：**口径不同**

```
🔴 A/B 口径不同 —— A 小于 750，B 不大于 750 —— 数值相同，口径不同（边界值上适用性不同）
```

它**不进**「不一致」那一档：读者看到「不一致」会以为是**数值**变了，
于是去查数值；而这里数值一模一样，差的是**边界**。
它也**不进**「三版一致 / 不需要改设计」—— 那正是 DR-003 说的打架。

### ⑤ 只在 **A 与 B 之间**比口径

第三版是**参照**，不是判定对象：
R48 说 "no more than"、GB 说「不大于」，让它参与判定只会造出假差异。
（这一条是实测出来的：初版让 C 也参与，一口气多出 **41 条假差异**。）

## 六、顺带挖出来的一个洞：闸门自己会**静默**死掉

出这一版时三道闸门红了，报的是「取 PDF 全文失败」，而 **stderr 是空的**。

真因：`spawnSync` 的默认缓冲是 **1 MB**，而闸门把 PDF 全文（中文 3 字节/字）
一次性读出来 —— 这次报告变大，文本到了 **1,052,019 字节**，越过 1 MB →
进程被 SIGTERM，`status=null`、`stderr` 空 → 闸门报「失败」但**说不出为什么**。

> **一个自己会静默死掉的闸门，比没有闸门更坏**：
> 没有闸门时问题**可见**；闸门死了的时候，它报的是「失败」，
> 而人会去查**被检查的东西**（PDF 全文），根本想不到是**闸门自己**撑爆了。

修法：所有读 PDF 全文的 `spawnSync` 显式给 `maxBuffer: 256 MB`（6 处）。
