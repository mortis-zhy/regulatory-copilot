## 二、动手前先量：A 与 C 到底差多少

按**数值**逐行比 A 与 C（319 个参数）：

| | 条数 |
|---|---|
| A 与 C 数值不同 | **3** |
| A 与 C 数值相同 | 240 |

**「3 条」是个陷阱** —— 它只是**数值**层面的差。
按**要求**层面（A 有 C 无 / C 有 A 无）来看，差得远得多：

| 差异类别 | 条数 | 谁要动手 |
|---|---|---|
| **C 有、A 无** | **33** | **出口按 C 做** —— 欧标有这条要求，国标没有 |
| **A 有、C 无** | **42** | **国内按 A 做** —— 国标有这条要求，欧标没有 |
| 数值不同 | 3 | 两套限值不同，按各自标准核 |
| 口径不同（数值同） | 3 | 恰好落在该值上的产品，适用性不同 |
| **合计** | **81** | |

> **出口时真正要动手的，是那 33 + 42 条** ——
> 它们**一个数字都没有**（不是限值不同，是**一条要求的有无**），
> 只比数值的话**一条都看不见**。

「某版没有这一条」两边都要求是**核过的**（`not-specified` + 逐条依据 + 条款号），
不是「没抽到」。

## 三、但要先把 **C 列的口径补齐** —— 否则这张表是假的

第一版量出来是 **40 条 A≠C**。逐条看，发现**大部分是假的**：

| 参数 | A | C | 为什么是假的 |
|---|---|---|---|
| AFS 同侧相邻发光单元水平距离上限 | ≤ 140 | 140 | C 原文是「**not exceeding** 140 mm」—— 口径没取到 |
| AFS 附加发光单元最小离地高度 | ≥ 250 | 250 | C 原文是「shall **not** be positioned lower than 250 mm」 |
| 紧急制动信号启动车速阈值 | > 50 | 50 | C 原文是「vehicle speed is **above** 50 km/h」 |

**根因**：比较口径的词表只认了少数英文写法 ——
`not exceed`、`more than`、`less than` —— 而 R48 实际用的是
`not **exceeding**`、`above`、`not lower than`、`may be **reduced to**`、
`may be **increased to**`、`by more than`……

**口径没取到 = 看起来像「C 没规定」** —— 于是 A–C 的差异被**放大成一片假差异**。

### 修法：英文的否定**作用域**

R48 的否定有三类，距离差很远：

| 形状 | 例 | 否定离取值多远 |
|---|---|---|
| 紧邻否定 | 「not exceeding 140 mm」 | 0～5 字 |
| **主语否定** | 「**None** of the additional lighting units … shall be positioned **lower than** 250 mm」 | **60～100 字** |
| 隔了并列词 | 「shall not be more than 3 m **and** the gap shall be more than 250 mm」 | 否定**不**作用于第二个比较词 |

所以不能把否定写进每一条正则 —— 那会漏掉前两种。
现在的算法：

1. 窗口 **160 字**；
2. 否定作用域 = 比较词之前、**同一句**内的那一段（句读切分 + 「句号+空格+大写」也算句子边界）；
3. 否定与比较词之间若隔着**并列词**（and / or / but）→ 否定**不**作用于该比较词；
4. **否定的方向不是简单对调** —— 法规语言的否定给出的是**含端点**的那一侧：
   - 「not more than X」= 值 **≤** X（不是「< X」）
   - 「not less than X」= 值 **≥** X（不是「> X」）

第 4 条正是 DR-002 的那个区别（`<750` 与 `≤750` 差在边界上），
所以**否定翻向必须是 `<→≥`、`>→≤`，不是 `<→>`**。

### 实测

| | 修之前 | 修之后 |
|---|---|---|
| C 列带口径的取值格 | 少（大量英文写法认不出） | **182 / 276** |
| A≠C（按数值+口径） | 40 条（**大半是假的**） | **3 条**（逐条回原文核过） |

比较口径的**已知答案用例**从 39 条加到 **61 条**（新增英文否定作用域、
主语否定、并列词阻断、否定翻向四组）。

## 六、这一版改了什么、没改什么

> C 此前没有参与任何判定，现在也没有。
