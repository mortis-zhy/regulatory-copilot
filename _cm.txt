fix(web): 交互测试发现并修复 3 个真问题

新增 audit_interact.py（上传流程 / API 契约 / 空态 / 重复操作）、
audit_depth.py（PDF 充实度）。

**1. PDF 按钮无重入锁 — 3 连点发起 3 次并发渲染**
每次 V8 渲染约 60 秒（Chromium 两次 pass），3 个并发会拉死浏览器。
修：用 pdfExportingRef 同步锁 + 按钮转圈 + 文案改「渲染中…」。
注意：只用 state 不够 —— 同一个 React batch 里的 3 次 click
都读到同一个旧值，锁不会生效。实测验证：3 连点 → 1 次请求。

**2. /report/pdf 空 body 返 500 → 400**
旧路径直接进渲染器再抛异常，用户拿到的是 stack trace 而不是可读错误。
修：提前校验 body（需 content 或 changes/parameters/evidence），返 400 + code。
前端补了 400 分支的 toast 文案。

**3. PDF 按钮被 Word 的 disabled 连带禁用**
PageHeader 的 disabled 来自「有无聊天回答」，但 V8 导出读的是
reports/last-report.json，与聊天无关。新建会话下用户就是导不出 PDF。
修：Word 保持 disabled，PDF 用独立 disabled（只看 pdfExporting）。
