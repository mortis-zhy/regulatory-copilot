体检工具：新增 audit_site.py（CDP 直连，走 8 条路由 x
A/B 路由可达性+控制台错误、C/D 交互+可访问性、G 三档响应式）

1. **真在运行错误（以前漏测到）**
   /projects、/documents、research、reports 四页报
   `ReferenceError: FolderOpen is not defined`
   Home.tsx 用了 <FolderOpen> 但 lucide-react 的 import 里没嬦。
   之前测试只看“页面能渲染”就放过了，此次改为回收 console 错误才拿到。

2. **a11y**
   - 侧栏展开/折叠按钮无 aria-label
   - 两个隐藏 file input 无 aria-label
   - 搜索按钮补 title
   修后两页 btnNoLabel / inputNoLabel 均为 0

3. **平板 768px 横向溢出 33px**
   顶栏是 justify-between 三段 flex，中间的模板选择器无 min-w-0 且不可压缩。
   修：header 改 min-h + flex-wrap + gap，模板栏加 min-w-0 shrink。
   修后 375/768/1440 三档均无溢出（手机 scrollW=375）。
