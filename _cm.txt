fix(htmlRenderV8): 统一 PDF 与 Web 的闭环统计，修 SVG 堆叠条分段

问题（比对 PDF 与 /review 时发现）:
- PDF 封面写「27 条候选差异中 21 条（78%）」，Web 工作台写「39 条中 30 条（77%）」
  —— 同一份报告给出两套数字。根因：htmlRenderV8 里的 extractClosureCounts
  是第二份实现，额外按章节标题过滤（/变化|候选|思路|对比|建议/），
  trustChecks.ts 的版本没有。
  对一份报告给出两个数字，正是读者会失去信任的形似。
- SVG 堆叠条的每个段都用 x = 100 * (1 - pct) 算开始，全部重叠在 0，
  实际只看得到最后一段。

修法:
- htmlRenderV8.extractClosureCounts 删除，改为转发 trustChecks.extractClosureCounts
  → PDF 与 Web 强制共用同一实现，不再可能漂移。
- SVG 段改为累加 offset（从左向右堆叠）。

验证（像素采样）:
- 条形图区域主色 #3a6a4e 2.0% / #c85329 14.5% / #9c8b6b 1.9%
  → 对应 13% / 77% / 10%，与表格完全一致
- PDF p3: 39 条 / 30 条 / 77% 与 Web 完全一致
- 单测 9/9, 6/6；verify_pipeline 43/0/2；139 页
