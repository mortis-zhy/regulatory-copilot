\section{ADB 测试方法（草案版新增）}

\subsection{ADB 测试类型}

\begin{enumerate}[leftmargin=2em]
    \item \textbf{静态识别测试}：测试 ADB 对静止目标的识别能力；
    \item \textbf{动态识别测试}：测试 ADB 对运动目标的识别能力；
    \item \textbf{眩目控制测试}：测试 ADB 在各种场景下避免对对向车辆眩目的能力；
    \item \textbf{响应时间测试}：测试 ADB 从识别到完成光型调整的时间；
    \item \textbf{降级模式测试}：测试 ADB 在部分功能失效时的降级能力；
    \item \textbf{环境适应性测试}：测试 ADB 在恶劣环境下的表现；
    \item \textbf{实车道路测试}：在实际道路上测试 ADB 的整体表现。
\end{enumerate}

\section{小结}

\begin{enumerate}[leftmargin=2em]
    \item 草案版相对现行版在测试方法上有较大扩充，特别是 EMC 测试和 ADB 测试；
    \item 草案版对 ADB 制定了专门的测试方法，填补了现行版的空白；
    \item 草案版对 LED 光源的加速老化方法进行了调整，新增 500 h 加速老化选项；
    \item 草案版对 EMC 测试限值进行了具体化，不再仅引用其他标准；
    \item 这些测试方法的变化对检测认证机构提出了新的能力建设要求。
\end{enumerate}
