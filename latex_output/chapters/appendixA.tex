\section{章节编排差异说明}

\subsection{逻辑差异}

三版本在编排逻辑上的主要差异：

\begin{enumerate}[leftmargin=2em]
    \item \textbf{现行版}：按照"基础 $\rightarrow$ 装置 $\rightarrow$ 认证"的层次组织；
    \item \textbf{草案版}：继承现行版思路，但增加了"智能照明系统"章节；
    \item \textbf{欧版}：采用更精细的"前/后/侧"分类方式。
\end{enumerate}

\subsection{详略差异}

三版本在内容详略上的差异：

\begin{enumerate}[leftmargin=2em]
    \item \textbf{现行版}：相对简洁，注重基础；
    \item \textbf{草案版}：内容有所增加，新增多个章节；
    \item \textbf{欧版}：内容最为详尽，包含大量技术细节。
\end{enumerate}

\subsection{整合差异}

三版本在章节整合上的差异：

\begin{enumerate}[leftmargin=2em]
    \item \textbf{现行版}：测试方法独立成附录；
    \item \textbf{草案版}：测试方法整合到相关章节，ADB 测试单独成附录；
    \item \textbf{欧版}：测试方法分散在各章节和附录中。
\end{enumerate}
