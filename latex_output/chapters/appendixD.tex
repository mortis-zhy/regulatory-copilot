\section{术语使用注意}

\begin{enumerate}[leftmargin=2em]
    \item 三版本术语体系基本保持一致，便于互译；
    \item 草案版新增术语主要分布在智能照明、装饰照明、电磁兼容等领域；
    \item 现行版中的部分传统术语（如"HID 灯专属术语"）在草案版中被整合；
    \item UN R48-09 中的英文术语是国际标准术语，应优先采用；
    \item 在中国标准的使用中，应使用草案版的中文术语。
\end{enumerate}
